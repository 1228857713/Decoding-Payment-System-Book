# 来源、版权与勘误

本网站阅读内容来源于《图解支付系统设计与实现》**V_0.1.0**，原著作者为 **隐墨星辰**。

- [作者原始 GitHub 项目](https://github.com/yinmo-sc/Decoding-Payment-System-Book)

## 版权联系与删除

如作者或其他权利人对本站内容有异议，请通过 [GitHub Issues 联系本站维护者](https://github.com/1228857713/Decoding-Payment-System-Book/issues/new?title=%E7%89%88%E6%9D%83%E8%81%94%E7%B3%BB)。请说明涉及的内容、权利依据及希望处理的方式。核实后，维护者将及时删除相关内容或下架网站。

## 文字与图示

正文使用 MinerU 识别后整理，核心图示保留原书图片。OCR 仍可能出现错字、遗漏、代码符号或表格识别问题；整理后的文字不能替代原始文件作为准确依据。

如发现错误，请在 [GitHub Issues 提交勘误](https://github.com/1228857713/Decoding-Payment-System-Book/issues/new?title=%E5%86%85%E5%AE%B9%E5%8B%98%E8%AF%AF)，写明章节、小节及原文片段，方便定位和核对。

## 阅读功能与数据

可使用顶部搜索检索全书，通过左侧目录切换章节，通过右侧目录定位小节。点击图示可放大查看，也可用 Tab 选中图示后按 Enter 打开，按 Esc 关闭。

字号与最近阅读位置仅保存在当前浏览器中，无账号同步。清除网站数据后，这些记录也会清除。
